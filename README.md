# 🐈‍⬛ Косатка — шахматный Telegram-бот

Чёрная кошка по имени **Косатка** (белая маска и пятно на носу — как у настоящей шиншиллы-табби) приглашает сесть за доску:
партия **с другом** по ссылке и партия **с самой Косаткой** (4 уровня силы).

Доска — **картинка**, нарисованная на лету: фигуры, подсветка хода, талисман в шапке, настроение Косатки в углу.
Ход делается кнопками: нажали фигуру — выбрали клетку. Нотацию вводить не нужно.

_Прежде чем читать дальше: Telegram не даёт ботам вставлять живое игровое поле прямо в ленту сообщений. В чат можно отправить картинку, кнопки или текст. Поэтому у игры два режима: **веб-доска** (открывается кнопкой из переписки — это Web App поверх чата, с доской, подсветкой и мгновенным откликом) и **доска-картинка** в самом чате с кнопками ходов. Работают оба режима на одной базе партий._

## Что умеет

- **Веб-доска (Web App)** — клик по фигуре на настоящей доске, подсветка возможных ходов, шахи, превращение, ходы SAN внизу. Запускается кнопкой «🕹 Играть в вебе» прямо из сообщения бота. Тех же карточек-доска и кнопки остаются запасным вариантом.
- **Партия с другом** — выбираете цвет, бот даёт ссылку `t.me/ваш_бот?start=…`. У каждого игрока своя карточка в своём чате, доска повёрнута под его цвет.
- **Партия с Косаткой** — уровни «Новичок → Мастер», любой цвет. Движок свой (alpha-beta), Stockfish и внешние бинарники не нужны.
- **Полные правила** — рокировка, взятие на проходе, превращение пешки (с выбором фигуры), шах, мат, пат, ничья по повторению, правилу 50 ходов и недостатку материала.
- **Сдача и ничья** — предложение ничьей сопернику с кнопками «Принять»/«Отклонить».
- **Состояние переживает перезапуск** — партии и приглашения лежат в SQLite. Если бота выключили, не дождавшись ответного хода движка, он доиграет его при старте.

## Веб-версия

```
chess_bot/web_server.py     # API (aiohttp) + отдача webapp
chess_bot/webapp/index.html # вся игра: одна страница, без зависимостей
```

- Игра запускается у бота кнопкой `InlineKeyboardButton(web_app=...)`; внутри Telegram открывается окно поверх чата, вне Telegram та же страница работает как обычный сайт.
- Пользователь в Telegram проверяется по подписи `initData` (HMAC-SHA256 на токене бота), поэтому партии не пересекаются между людьми. Без Telegram — гость по cookie.
- API: `/api/game/new`, `/api/game/{id}`, `/api/game/{id}/move`, `/api/game/{id}/resign`, `/api/game/{id}/draw`, `/api/join/{token}`, `/api/last`.
- Фигуры на веб-доске нарисованы векторно (SVG) — не зависят от шрифтов на устройстве.

### Запуск веб-версии отдельно (без токена)

```powershell
py -3 -m chess_bot.web_server --host 127.0.0.1 --port 8080
```

Откройте <http://127.0.0.1:8080/> — можно играть с Косаткой прямо в браузере, по ссылке `?as=Имя` задаётся имя игрока. Так удобно проверять интерфейс до подключения к Telegram.

### Подключение к боту

| Переменная | Значение |
|---|---|
| `WEBAPP_URL` | HTTPS-адрес игры, например `https://kot.example.com/webapp/` |
| `WEBAPP_HOST` / `WEBAPP_PORT` | где слушать API (по умолчанию `0.0.0.0` / `8080`) |

Если `WEBAPP_URL` задан, бот при старте сам поднимает веб-сервер на `WEBAPP_PORT` и добавляет в клавиатуры кнопку «🕹 Играть в вебе». Telegram принимает только HTTPS с сертификатом, поэтому локальный `localhost` для кнопки не подходит: нужен домен с TLS или HTTPS-туннель. Если `WEBAPP_URL` не задан — работают только доски-картинки.


## Три темы оформления

| Тема | Вид |
|---|---|
| `midnight` — «Ночная Коска» | тёмно-сливовый фон, кофейно-бежевая доска, янтарный акцент (по умолчанию) |
| `emerald` — «Мятная лапка» | тёмно-зелёный фон, кремовая доска, мятные акценты |
| `sakura` — «Розовый нос» | винно-розовый фон, кремовая доска, розовые акценты |

Тема задаётся в коде через `theme_for()` в `chess_bot/bot.py`; картинки рисует `chess_bot/app/images.py` (Pillow, без скачивания шрифтов и картинок — только системные).

## Установка

Нужен Python 3.10 или новее.

```powershell
# из папки с проектом
py -3 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

На Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Токен

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя.
2. Скопируйте токен вида `123456789:AAH...`.
3. Задайте его одним из способов:

```powershell
# способ 1: переменная окружения
$env:TELEGRAM_BOT_TOKEN = "123456789:AAH..."
```

или создайте файл `.env` в папке проекта:

```
TELEGRAM_BOT_TOKEN=123456789:AAH...
```

## Запуск

```powershell
py -3 -m chess_bot.bot
```

В консоли появится `Бот запущен`. Откройте своего бота в Telegram и отправьте `/start`.

## Как играть

| Действие | Как |
|---|---|
| Партия с Косаткой | «🐈‍⬛ Играть с Косаткой» → уровень → цвет |
| Партия с другом | «👥 Позвать друга» → цвет → отправьте другу ссылку |
| Ход | нажать фигуру → нажать клетку |
| Взять ход назад | «↩️ Другая фигура» |
| Сдаться / ничья | кнопки под доской |
| Продолжить после перезапуска | `/start` покажет незавершённую партию |

Команды: `/start` — меню с обложкой, `/help` — правила, `/new` — новая партия.

## Структура

```
chess_bot/
  bot.py              # aiogram: команды, кнопки, карточки-картинки, ход бота, рестарт
  app/
    engine.py         # движок: alpha-beta, оценка позиции, уровни сложности
    store.py          # SQLite: партии, приглашения, привязка сообщений к игрокам
    images.py         # Pillow: доска-картинка, векторные фигуры, Косатка, темы
    board_ui.py       # inline-клавиатуры и текстовая история ходов
tests/
  test_chess_bot.py   # 15 тестов: правила, хранилище, кнопки
requirements.txt
```

## Тесты

```powershell
py -3 -m unittest discover -s tests -v
```

Проверяются: законность ходов и очередь хода, запрет чужих ходов, превращение пешки, мат и завершение партии, сдача и ничья, движок находит мат в 1, поворот доски, длина `callback_data` под лимит Telegram (64 байта).

## Отрисовка

- Доска рисуется в `chess_bot/app/images.py` на лету: 96 px на клетку, карточка ~940×1050 px, PNG примерно 25 КБ.
- Фигуры — векторные полигоны Pillow (пешка, ладья, слон, конь, ферзь, король), поэтому не зависят от шрифтов с шахматными символами.
- Косатка в шапке нарисована тем же кодом: уши, белая маска, янтарно-зелёные глаза, пятно на носу.
- При каждом ходе карточка обновляется через `edit_message_media` — сообщение не «плодится».
- Подписи ищут системные шрифты Windows (`segoeuib.ttf`, `segoeui.ttf`); на Linux отрисуется шрифтом по умолчанию.

## Заметки по эксплуатации

- **База** — файл `chess_bot.db` рядом с проектом; путь можно переопределить переменной `CHESS_DB`.
- **Хостинг** — используется long polling, поэтому нужен только исходящий доступ в интернет, вебхук и домен не требуются.
- **Автозапуск** — на Windows «Планировщик заданий», на Linux `systemd`-юнит с `ExecStart=/путь/.venv/bin/python -m chess_bot.bot`.
- **Движок** — считается в отдельном потоке, поэтому бот не «зависает» на время хода. Уровни: 1 — новичок (глубина 1), 4 — мастер (глубина 4, до 5 секунд на ход).
- Если бота используют несколько человек одновременно, партии независимы: у каждой своя блокировка и своя карточка-доска.
